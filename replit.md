# Project overview

This is a static Portuguese event landing page built with plain HTML, CSS, and JavaScript.

## Run locally on Replit

Start the **Start application** workflow. It serves the project root on port 5000 with:

```sh
python3 -m http.server 5000 --bind 0.0.0.0
```

No dependency installation or environment secrets are required for the site preview. The signup form submits to the existing external ActiveCampaign endpoint configured in `index.html`.
